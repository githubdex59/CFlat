# C Flat

A Web framework written in C#.


## Features

### Current
- Http server that routes and renders your code
- Cookie support
- Javascript
- CSS(manual)

### Planned
- CSS(generated)
- More premade Javascript scripts

## Run Locally

**Prerequisites:** Git, .NET 9.0 SDK or later, make(optional)

Clone the project:
```bash
git clone https://github.com/githubdex59/CFlat.git
```
Change directories into it:
```bash
cd cflat
```
Run the test program:
```bash
make test
```
