Detailed Description

The class used to define a standard web page.

Populate the _head property with any data needed there(title is already set) and fill _children with the page's contents. When making your own page by extending this class, do the following:

  • Name your class the path excluding slashes, after slashes capitalise the letter, e.g. /foo/bar/bazz/buzz => FooBarBazzBuzz
  • Make a constructor as follows:
    public FooBar() : base(
    new List<HtmlElement>(),
    new Attributes(),
    "FooBar",
    new HtmlHead(new List<HtmlMeta>())
    )
    {
    ...
    }
