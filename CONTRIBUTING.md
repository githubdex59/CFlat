First of all thank you for wanting to contribute.
I'm happy to accept any contributions as long as they follow the contribution rules.

# Rules:
- No AI, this extends to LLMs, image generators, video generators, or any kind of generative AI.
- No CRLF, either manually convert it, use WSL, or use mac/linux
- Always make a test for any new features you add
- When commiting, run `make prepare_for_commit`
